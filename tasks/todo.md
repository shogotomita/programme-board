# Day A/B メゾサイクル 5週（第3ルーティン）

## Goal

既存の `iron-16` と `mav-mrv-5` を残したまま、Day A/B 交互スプリットの5週メゾサイクルを第3ルーティンとして追加する。

## Decisions

- ID: `ab-meso-5` / 表示名: `A/B メゾ 5週`
- 毎週固定: 月A・火B・水A・木B・金A（帳尻合わせなし）
- OHP: メイン表から **-5%**、セットは他メインより1少ない（W3例どおり強化期は3セット）
- 補助プレス（CGBP / インクライン）: その週メイン%から **-7.5%**（ベンチ1RM基準）
- ディロード・メイン: **52.5%** × 5 × 2、RPE5
- 補助セット: サイドレイズ/カール/シュラッグ/ノルディック **3**、懸垂 **4**（W5は半減）
- ノルディック: 他補助よりレップやや低め（W3例 8–10）
- iron-16 の MAV超/MRV `volumeAudit` は**適用しない**（処方どおり。ボリューム表は表示のみ）
- フェーズ: W1=`mav` / W2–3=`build` / W4=`mrv` / W5=`deload`（ラベル用。蓄積→強化→ディロード）
- 補助の絶対重量: レッスンどおり実測寄り（シュラッグ≈50kg台、カール≈30kg台）。DL%機械引きはしない
